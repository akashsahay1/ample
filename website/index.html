Everything a PHP project needs, locally

A PHP version per project

Run a legacy app on PHP 7.4 next to a new one on 8.5. Install more versions from the app, and php in a project folder uses that project’s version.

Folders become .test sites

Every folder in a parked directory is served at http://folder.test. Link any other folder in one click.

One-click HTTPS

A local certificate authority, limited to .test and localhost, issues trusted certificates for your sites.

New project

Start a Laravel, WordPress or plain PHP project with its database created and wired into .env or wp-config.php.

Works next to XAMPP and Herd

See which program is holding a port, stop it on request, and import projects and databases from XAMPP or Laravel Herd without changing them.

App, tray and CLI

A desktop app with a tray icon for the day to day, and the ampls command for everything else.

# serve a folder, pin its PHP version, enable HTTPS
> cd D:\work\shop
> ampls link
> ampls isolate 8.3
> ampls secure
# bring projects over from Laravel Herd
> ampls import herd --dry-run
